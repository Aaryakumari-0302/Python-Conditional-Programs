Python Practice Programs - Advanced Level (Questions 51-60)
===========================================================

This folder contains 10 beginner-friendly Python programs.
Each program is in its own .py file, and the file name is the full question.

Rules followed:
- Only "if" and "else" are used (no "elif").
- Simple code with comments, easy to read.

How to run a program:
    python "<file name>.py"

Notes:
- Question 56: weekday numbers are 1 = Monday ... 7 = Sunday,
  so Saturday (6) and Sunday (7) are the weekend.
- Question 59: the stored password is "Secret123". Change the
  stored_password line in the file to use a different one.

Programs included:
51. Valid triangle from three angles (sum exactly 180)
52. Four-digit number divisible by sum of first and last digits
53. Merit certificate (marks above 85 in at least 4 of 5 subjects)
54. Debt-to-income ratio below 40%
55. Perfect number
56. Weekend check from weekday number
57. Refund eligibility (within 7 days and unused)
58. Point on circumference of a circle
59. Password match and minimum 8 characters
60. Right-angled triangle from side lengths
