PYTHON PROGRAMS - PART 2: USE IF-ELSE ONLY (Questions 31 to 50)
================================================================

Rule followed: only "if" and "else" are used. "elif" is NOT used anywhere.

Contents
--------
20 Python files. Each file solves one question, and the file name is the
complete question sentence.

  Simple Level (31-40)
  Medium Level (41-50)

How to run a program
--------------------
1. Install Python 3 from https://www.python.org
2. Open a terminal / command prompt in this folder.
3. Run a file, for example:

   python "Write a program to check whether a number is a multiple of 11 or not.py"

4. Type the input values when the program asks for them.

Notes
-----
- The Rupee sign appears in two file names; inside the programs it is
  written as "Rs" so it prints correctly in every terminal.
- The full stop at the end of each question is left out of the file name
  so it does not clash with the ".py" extension.
- Programs use simple input(), print(), if and else, with a few loops where
  needed (digit sum, factorial, five item prices).
- Question 46: enter a positive transaction amount for a deposit and a
  negative amount for a withdrawal.
- Question 47: a strong number is one where the sum of the factorials of its
  digits equals the number (for example 145 = 1! + 4! + 5!).
