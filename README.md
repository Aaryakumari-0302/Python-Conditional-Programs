# Python Conditional Programs - Batch 5 (if-elif-else)

30 beginner-friendly programs (Questions 61 to 90). Every program uses `if`, `elif` and `else`.

Each `.py` file has two solutions:
1. **Solution 1:** Normal method (plain `if-elif-else`)
2. **Solution 2:** Function method (`if-elif-else` inside a function)

## How to run

```
python file_name.py
```

Example: `python height_classification.py`

## Notes on assumptions

- **Q85 (courier charge):** the question gives no prices, so sample charges are used (Rs. 50 / 100 / 180 / 250). Change them in the file if you want.
- **Q90 (transaction risk):** the question asks you to define thresholds, so the thresholds are written in the comments at the top of the file.
- **Q73 (library fine):** the per-day rate of the matching slab is applied to all overdue days.
- **Q75 (taxi fare):** Rs. 50 covers the first 2 km, Rs. 15 per extra km up to 10 km, then Rs. 12 per km beyond 10 km.
- **Q78 (project submission):** enter days before the deadline; use a negative number if late.
- **Q83 (water bill):** each slab is charged only for the litres inside that slab.
